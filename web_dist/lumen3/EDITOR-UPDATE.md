# 灯光与姿态工作台：交互更新

## 时间轴启动修复与视图内关节按钮

- 修复底部操作说明与界面初始化之间的冲突。此前该错误会中断后续初始化，导致时间轴未创建、灯光布局停留在旧状态。时间轴现直接包含在页面结构内，再绑定统一播放功能；初始化也可兼容说明节点缺失的情况。
- 右侧两个灯光分组调整为：上方“灯光分析与光源列表”，下方“当前灯具参数”。两组各自展开 / 收起，选中灯具的参数保持在下方。
- 三维视图**内部右上角**常驻“显示关节点 / 隐藏关节点”按钮，不受左侧分类或面板收起影响，并与工具栏、动作校准页开关同步。

## 多资产大纲、固定时间轴与选择 / 拟合修复

- 时间轴固定在中间三维 / 拍摄工作区底部，两侧属性栏独立滚动。资产动画多于两条时，轨道区可滚动；所有轨道仍由同一播放指针驱动。
- 三维资产页改为场景大纲。可批量或逐次追加多个 FBX / OBJ 及材质、贴图。每个文件独立选择、展开节点及显隐；选择新文件不会替换先前资产。同一源文件重复导入会关联已有项。
- 自动区分角色、模型、摄像机、混合场景、动画资源和骨架。仅含摄像机的 FBX 可直接导入；包含摄像机的场景保留其原生父级与动画关系。多台摄像机可在大纲中选中，再点击“设为拍摄视图”。
- 选中资产后可追加多个兼容的动画文件，也可将大纲中已有资源的动画绑定到选中资产。每个资产单独选择动画片段；切换或隐藏其中一个资产不影响其他资产，隐藏资产也保持统一时间取样。动画只按兼容节点 / 骨架绑定，不猜测跨骨架重定向。
- 工程保存整个大纲、各资产可见性、节点变换、动画片段与时间轴状态。角色 / 模型文件及贴图仍需重新关联；纯摄像机或动画资源可随工程恢复。

三维视图顶部提供持续可见的 **关节：显示 / 隐藏** 开关，与动作校准页开关同步；显示后可直接选择关节编辑。点击三维视图空白处会取消选择，清除操作手柄、大纲选中状态和注视目标球；场景对象不会被删除。

**拟合锁定相机** 默认开启，锁定的是拟合算法，不妨碍用户手动编辑相机。先手动调整拍摄机位、朝向和视场角，再执行动作拟合：只调整人物根位置、深度及姿态，保持相机位置、旋转、视场角和投影不变。自动识别后的动作校准也遵循此锁定；只有关闭锁定才允许重估相机。“仅锁定视场角”与完整的相机锁定是不同选项。按照片标记点拟合动作始终使用当前拍摄机位。

## 显示即可编辑与手动关键帧

“动作校准”页简化为两个独立开关，默认关闭：

- **显示关节**：显示左侧三维关节点。点击选中，W 移动、E 旋转；编辑完成关闭显示即可。导入 FBX 则显示其真实骨骼关节点，可选中并编辑；OBJ 没有骨骼，只能编辑模型整体变换。
- **显示标记点**：显示右侧照片叠图标记，显示后即可拖动。拖动只修改标记位置；点击“按标记点拟合动作”才修改默认人体姿态，拍摄相机保持不变。关闭显示只隐藏标记，不清除已编辑位置。镜头联合校准仍可在高级选项中单独执行。

三维关节与照片标记是两套独立的编辑对象。蓝灰色照片点为尚未确认的白模投影，拖到正确位置后转为已确认数据。全身拟合至少需要 5 个已确认点；单臂拟合可使用完整的肩、肘、腕 3 点。

### K 帧

1. 选择关节、导入骨骼、拍摄相机或灯具。
2. 在底部时间轴定位帧，调整当前对象。
3. 按 **S**（也支持 K）或点击 **K帧** 记录；同一对象同一帧再次记录会替换。
4. 定位其他帧、调整并再次记录，播放或拖动时间轴查看插值。

底部菱形显示当前选中对象的关键帧，支持前 / 后关键帧、删除当前关键帧和“全部K帧”。位置、缩放、强度、色温与灯面尺寸等数值采用线性插值；旋转使用四元数球面插值；开关、灯具类型等离散属性保持上一关键帧状态。关键帧时间以秒保存，切换 FPS 不改变实际动画时长。

默认人体记录原生骨骼局部旋转；选中的控制关节会记录相关的 IK 肢体链，保持原生骨长。导入骨骼记录其局部变换。手动 K 帧在导入动画之后取样，覆盖已记录的对应通道；未记录的导入通道继续播放。当前没有自动 K 帧或曲线编辑器，修改后需主动记录。

手动关键帧支持撤销 / 重做，随工程保存；导出的场景 JSON 也包含关键帧通道和插值约定。这些数据仍需下游软件明确支持才可直接执行。

## 统一时间轴与场景坐标修复

界面底部新增共享时间轴，人物与摄像机从同一场景秒数取样，不再各自累计播放时间。支持播放 / 暂停、空格键、首尾帧、逐帧步进、拖动定位、当前帧输入、FPS、播放起止区间和全局循环。两条轨道分别显示人物与摄像机片段，可启用 / 关闭并设置秒数偏移。短片段到末尾保持最后一帧，循环由全局时间轴控制。

推荐导入流程：

1. 左侧“三维资产”选择 OBJ / FBX 及其 MTL、贴图等配套文件，或直接选择文件夹。
2. 默认选择“保留源世界位置”。FBX 从文件读取单位及向上轴；缺失信息会提示采用假设。OBJ 没有可靠单位元数据，默认 1 单位 = 1 米，请明确选择实际单位和向上轴。
3. 读取模型后，选择人物动画片段。模型 FBX 中的摄像机、摄像机父级及其变换动画会一起识别，自动接入摄像机轨道；也可独立导入摄像机文件，再点击“应用并接入统一时间轴”。
4. 在底部统一播放或拖动时间。人物动画与摄像机文件可以使用不同单位，但必须描述同一源世界空间；单位换算不等于将两个无关场景自动对齐。

已移除“默认把人物缩放到 1.8 米并移到原点”的导入行为。若选择“共享场景归一化”，人物和摄像机都使用同一个场景居中 / 缩放变换；摄像机自身的单位转换只执行一次。人物原始根节点、动画根运动、摄像机父级与旋转层级均保留。摄像机位置和方向始终在统一米制、Y 向上的工作台坐标中输出，并记录源坐标设置与转换矩阵。

动画文件应来自兼容骨架。可匹配的位移轨道会按动画与模型单位比例转换；导出轴不同的骨架会拒绝直接套用，避免错误变形。当前支持静态 OBJ 和可解析的 FBX 变换 / 骨骼动画；OBJ 本身不携带骨骼动画。特殊约束、复杂控制器或无法解析的镜头曲线，应先在源软件烘焙为标准 FBX 关键帧。

工程保存时间轴、轨道状态 / 偏移、导入坐标设置、源到世界变换以及摄像机层级与可解析动画。重新打开工程仍需关联原模型及贴图文件；保存的摄像机变换动画可从工程恢复。旧工程保留旧的高度归一化设置，以免直接改变旧构图；新导入请使用“保留源世界位置”。

文件夹资源按相对路径匹配；多个同名贴图无法确定对应关系时不会随意选取。OBJ 支持多个引用的 MTL 材质库。

## 独立动画、摄像机与地面

左侧“三维资产”新增独立导入入口：

- 动画：先读取人体模型，再选择动画 FBX 或 Three.js AnimationClip JSON。兼容的轨道按骨骼名称绑定；不替换模型。导入后在“动画片段”中选择、播放或拖动时间。不同骨架不自动重定向，模型与动画的源单位应一致。导入结果会列出匹配和跳过的轨道数。
- 摄像机：可单独读取含摄像机的 FBX，或本工具导出的 scene.json。选择相机、坐标对齐与注视距离，再点击“应用到拍摄相机”。有动画的 FBX 可选择镜头片段、播放和拖动时间。当前支持透视相机。
- 同一源场景导出的模型和相机可选择“沿用当前模型的坐标归一化”，保留相对位置；独立相机选择“源坐标 → 工作台米”，自行确认单位比例（厘米为 0.01）。JSON 使用工作台米坐标。原图存在时，拍摄画幅沿用原图比例；无原图时沿用导入相机画幅。
- 工程文件保存额外导入的动画轨道及绑定信息、摄像机层级与可解析动画、统一时间轴和地面状态。恢复模型仍需重新选择原模型文件。

三维视图顶部“地面：显示 / 隐藏”同时控制地面和网格；隐藏后不渲染地面接触阴影。该操作可撤销，工程与 JSON 会记录地面状态。

灯光页顺序固定为：原图分析按钮、光源分析设置与结果、光源列表、选中灯具参数、经典模板。分析设置默认展开。

## 属性分类

- 资产页显示当前导入资产的变换、骨骼和动画属性。导入文件仍在左侧“资产”分类。
- 灯光分析仅出现在灯光页。最上方独立分析按钮；随后为光源选择、选中灯具属性、经典模板。
- 可添加附加灯，最多八盏；附加灯可删除。模板会替换当前整套灯光，可撤销。

## 图片动作与镜头

打开“显示标记点”后，直接拖动照片叠图上的同名标记，无须按顺序标定。绿色为识别或人工确认点，蓝灰色仅为尚未确认的白模投影。编辑完成点击“按标记点拟合动作”，再更新人体；松手不再自动校准。需要修改镜头时，可另行展开高级选项执行联合校准。

新照片默认自动比较镜头方向，并分别处理人物动作与相机，不预先强制站直、抬头或微俯拍。镜头拟合采用身体参考点，避免伸出手臂的误差牵动整个镜头。JSON 额外记录摄像机相对骨盆的位置。

单图无法唯一确定深度、真实焦距、身体比例及摄像机位置。检查叠图、投影残差和方向歧义提示；必要时明确指定仰拍、平视或俯拍约束。以上是可修正的三维初稿，不是精确测量。

## 撤销与重做

顶部“撤销 / 重做”，快捷键 Ctrl+Z、Ctrl+Y 或 Ctrl+Shift+Z。支持模型姿态、关节点、摄像机、灯光、模板和资产变换。更换参考图片或导入新资产会重建撤销历史；文本输入框保留自身的文字撤销。

## Maya 常用操作

| 操作 | 快捷键 |
| --- | --- |
| 环绕观察 | Alt + 鼠标左键 |
| 平移观察 | Alt + 鼠标中键 |
| 推拉观察 | Alt + 鼠标右键；滚轮亦可缩放 |
| 选择 / 移动 / 旋转 / 缩放 | Q / W / E / R |
| 聚焦选中对象 | F |

观察视图导航不改变拍摄相机。摄像机请调整位置、注视点或视场角；灯光缩放改变灯面尺寸，默认人体采用等比缩放。位移摄像机或灯具时保持各自注视目标不变。

## 给图片 / 视频 AI 的参考

原图负责身份、外观与材质；白模截图负责目标姿态、构图和光照意图；自然语言提示词解释可见效果，JSON 提供坐标和矢量辅助约束。不要把白模截图作为视频首尾帧。只有下游接口明确支持三维参数时，才能期待直接绑定这些参数；普通图片编辑模型不保证物理执行。
