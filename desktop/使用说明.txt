Chouka IF Bridge 内网试用说明（Windows）

仅供获得授权的内部员工试用。请使用完整的 ChoukaIFBridge.zip，勿单独复制 EXE；程序还依赖同目录的 runtime、server 和 manifests。必须等管理员确认 HTTPS 8443 已切换至本包对应的新证书后，再按下面步骤信任测试 CA；旧版网站证书不能用于此流程。新证书有效至 2027-10-20，试用结束后请按本说明移除信任。CA 私钥不在安装包，也不在 Linux 网站服务器上。

一、先核对并信任测试证书（只在本人可信的测试电脑操作）
1. 解压完整 ZIP。在解压后的 ChoukaIFBridge 文件夹中找到 Chouka-IF-Test-CA.crt。
2. 在此文件夹打开 PowerShell，执行：
   Get-FileHash -Algorithm SHA256 .\Chouka-IF-Test-CA.crt
   本版文件 SHA-256 必须是：D832BEB8597484F14845FA3883642FEAAA46EAD8D98F7D9A79FC0FF6FF7A9048
   不相符就停止，不要导入。证书本身的 SHA-256 指纹为：43EAFC9D375C8F3B85435FCA04FA1B46EC5A64069323655502BBD08D0EAB0C66。
3. 双击 Chouka-IF-Test-CA.crt →“安装证书”→“当前用户”→“将所有的证书都放入下列存储”→“浏览”→“受信任的根证书颁发机构”→完成。Windows 如询问是否信任“Chouka IF Test CA 2026-10”，核对名称后再确认。不要导入其他来源的同名证书，也不要安装任何私钥。
4. 完全退出并重新打开 Chrome 或 Edge。访问 https://dinghaichouka.youku.com:8443/ ，确认浏览器不再提示证书错误，然后用自己的 Chouka 账号登录。若浏览器仍提示证书错误、域名不符或证书链异常，不要点“继续访问”，请联系管理员核对线上证书是否已切换到本测试 CA。

二、安装和使用本机桥接
1. 如旧版桥接器已运行，先确认没有正在进行的 IF 任务，再从旧版托盘图标选择“退出程序”。它不会自动替换旧进程或抢占端口 8278。
2. 新员工可在解压后的文件夹直接运行 ChoukaIFBridge.exe。需要开始菜单快捷方式时，在该文件夹运行 Install.ps1（右键“使用 PowerShell 运行”）；它安装到当前用户的 Programs\ChoukaIFBridge，不会覆盖已有安装。安装来源与哈希未经确认时不要忽略 Windows 安全警告。
3. 如已安装旧版，退出旧程序后，先在“%LOCALAPPDATA%\Programs”中把旧 ChoukaIFBridge 文件夹改名备份，再从新解压的文件夹运行 Install.ps1。不要移动或卸载单独的 IF CLI（%LOCALAPPDATA%\Programs\ifs\ifs.exe）。
4. 打开程序后：若显示“IF CLI 已安装（无需再安装）”，跳过第 1 步；未安装时按提示确认安装。按“2 登录 BUC”完成浏览器授权；程序通常会自动启动桥接，未启动且端口空闲时按“3 启动桥接”。看到“BUC 已授权”和可用模型数后即可使用。
5. 一台员工电脑只运行一份本机桥接。若显示 8278 被其他程序占用，先查明并正常退出旧桥接，再刷新；不要强制结束其他人的任务。需要 Windows 登录后自动启动时，勾选程序内的复选框。

三、在浏览器试用 IF
1. 必须在 https://dinghaichouka.youku.com:8443/ 打开 Chouka；旧 HTTP :8199 虽可继续访问其他功能，但 Chrome/Edge 会拦截它读取本机 IF 桥接。
2. 登录网页，进入 IF 生图/生视频卡片，检查模型列表。浏览器如询问是否允许访问本地网络，请在确认页面域名和证书无误后允许；桥接始终只监听本机 127.0.0.1:8278。
3. 可自选一个低成本任务小范围试用。生成由 IF 服务端处理，本机桥接使用本人 IF CLI 的 BUC 授权。请勿在未知网站测试或导入来历不明的证书。

排查
- “Failed to fetch”且提示 not a secure context：检查是否误用了 http://...:8199，改用已信任的 HTTPS :8443。
- HTTPS 提示证书错误：停止操作，核对本说明中的证书 SHA-256、有效期和网站域名；不要通过关闭浏览器安全检查绕过。
- 浏览器提示本地网络权限：确认来源是 Chouka HTTPS :8443，再允许本地访问。
- 网页提示端口 8278 无响应：确认桥接主窗口显示“本程序运行中”及 BUC 已授权，端口没有被旧版占用。旧版桥接不会自动升级。
- 员工已安装 IF CLI：安装按钮会自动禁用，无需重装 CLI；直接登录 BUC 并启动桥接。

试用结束后的证书撤销：按 Win+R 输入 certmgr.msc，在“受信任的根证书颁发机构 → 证书”中找到“Chouka IF Test CA 2026-10”，核对指纹后只删除这一张测试 CA；不要删除其他企业证书。若由企业统一安装，联系 IT 统一撤销。此测试 CA 到期前请迁移到公司正式 CA 或受信任的公有证书。
